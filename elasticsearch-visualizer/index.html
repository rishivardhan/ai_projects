Elasticsearch, From Scratch

An interactive teardown of text analysis, the inverted index, and relevance scoring — no server, no dependencies beyond this page.

1. Documents 2. Analysis Pipeline 3. Inverted Index 4. Query & Scoring 5. Results

1 · Document Ingestion

Elasticsearch is a document store before it is anything else. Each document you add below gets a numeric ID and is queued for analysis. Four samples are preloaded so the rest of the page works immediately — edit, delete, or add your own to see everything downstream recompute live.

Adding, editing, or deleting a document instantly rebuilds the index below.

2 · The Text Analysis Pipeline

Before a document's text becomes searchable, an analyzer tears it apart: lowercasing, splitting into tokens, discarding low-information "stop words", and reducing words to a crude root (stemming). Pick a document to watch it happen stage by stage.

3 · The Inverted Index

This is the data structure that makes search fast: instead of scanning every document for a word, Elasticsearch looks the word up once and gets back the exact list of documents (and how often it appears in each). Every stemmed term produced by the pipeline above becomes one row here.

Term Posting List — Doc (TF) Document Frequency (DF) BM25 IDF (current corpus)

4 · Query Engine & Relevance Scoring

A search query is analyzed with the exact same pipeline as documents, then matched against the inverted index. AND requires every query term to be present; OR accepts documents matching any of them. The scoring model decides how those matches turn into a ranked number.

5 · Ranked Results & Score Breakdown

Documents are ranked by score, highest first. Expand a result to see, term by term, exactly how its score was computed — the same numbers Elasticsearch's explain API would show you.

Built as a self-contained teaching tool. Stemming and stop-word logic are simplified for clarity, not production-grade linguistics — real Elasticsearch analyzers (Porter stemmer, language-specific stop lists, ICU normalization) are considerably more sophisticated.
